# Nicholas Seve — Minimal Portfolio

## Preview locally
Open `index.html` in a browser.

## Replace the sample paintings
The sample images are remote placeholder images. To use your own paintings:

1. Put your images in the `images` folder.
2. In `index.html`, change an image source from a URL to something like:
   `images/painting-01.jpg`
3. Change the title, year, and medium in the caption.

## Free hosting
The simplest free option is GitHub Pages:

2. Upload `index.html`.
3. In the repository, open Settings → Pages.
4. Select the `main` branch and root folder.
5. GitHub will give you a free `github.io` address.

## Custom domain
Then add the domain under GitHub Pages → Custom domain and follow the registrar's DNS instructions.

No server, database, framework, or monthly hosting bill is required.
